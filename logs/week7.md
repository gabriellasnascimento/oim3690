## session 13 
## what I learned 
- Responsive design = "one website, many devices", and the viewport meta tag is essential so mobile browsers don't treat your site like a desktop-only page.
- How mobile-first design works and how media queries chage layouts at different breakpoints 
- Why GET vs POST matters 
- Why labels matter for accessibility and that for must match the input's id (and name is the key that gets submitted).
- The viewport meta tag is essential for responsive design—without it, mobile browsers scale pages strangely and layouts don’t behave as expected.
- How responsive layout works with mobile-first thinking: start with a simple layout for small screens, then enhance for larger screens using breakpoints (media queries or framework breakpoints).
- In forms, labels improve accessibility, and for must match the input id. Also, the name attribute controls what data is actually submitted.
- How CSS frameworks (like Tailwind) speed up design using utility classes, but you still need to understand what each class does so you can debug and customize the layout yourself.
